# Deal Witness — Synthetic Evidence Pack

All material in this directory is synthetic demo content. **Brassleaf Works**, **Lanternline Credit**, every named person, every event, and every deal term are invented and are not modeled on an actual company, transaction, or person.

The pack contains the five canonical evidence types in chronological order:

1. [`01-negotiation-call.md`](01-negotiation-call.md) — initial conversation (`HEARD`)
2. [`02-internal-message.md`](02-internal-message.md) — handoff reminder
3. [`03-approved-deal-memo.md`](03-approved-deal-memo.md) — approved record (`CONFIRMED`)
4. [`04-maya-exit-answer.md`](04-maya-exit-answer.md) — explicit handoff answer
5. Closing draft — [`05-closing-draft-v7.md`](05-closing-draft-v7.md) is the omitted version; [`06-closing-draft-v8-corrected.md`](06-closing-draft-v8-corrected.md) is the corrected version (`IN CONTRACT`)

The two closing-draft files are versions of one evidence type. They remain separate so a demo or test can compare the `READY → HOLD FOR REVIEW → READY` transition without rewriting history.
